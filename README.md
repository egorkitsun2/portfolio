# Portfolio v0.3 — release candidate

Тёмное одностраничное портфолио Егора Кицуна. Основная специализация — разработка сайтов и веб-приложений. Пять веб-проектов показаны первыми, ROS и Архивариус — в дополнительном блоке. Контакты и краткие сведения о проектах открываются в нативных модальных окнах. Семь отдельных страниц содержат технические кейсы.

Локальная сборка не требует npm, сторонних пакетов и этапа компиляции.

## Ручная приёмка

Из корня проекта:

```powershell
python scripts/build.py
python scripts/preview.py --port 8010
```

Откройте http://127.0.0.1:8010. Сервер доступен только на этом компьютере. Остановка — Ctrl+C.

Готовая папка: `release/portfolio-v0.3-rc1`. Архив с теми же файлами: `release/portfolio-v0.3-rc1.zip`. Сборка содержит только выбранные файлы сайта. Исходные скриншоты владельца, отчёты, резервная копия, инструменты проверки и исходники других проектов в неё не входят.

## Подключение видеодемонстрации

После предоставления реального ролика положите его в `assets/projects/` и задайте `video` нужного проекта:

```javascript
video: {
  src: "assets/projects/имя-реального-файла.mp4",
  poster: "assets/projects/имя-реального-скриншота.png",
  captions: "assets/projects/имя-субтитров.vtt",
  description: "Текстовое описание показанного сценария."
}
```

Пример показывает структуру данных и не создаёт ссылок в сайте. Укажите только существующие файлы; `poster` и `captions` необязательны. Видео использует стандартные элементы управления, не запускается автоматически, не загружается заранее и останавливается при закрытии модального окна. После добавления ролика необходимо проверить воспроизведение, звук и субтитры.

## Маршруты и метаданные

robots.txt и sitemap.xml используют действующий адрес https://portfolio-4lm.pages.dev/. Sitemap перечисляет главную и семь кейсов с адресами без расширения. Корневой 404.html предназначен для штатной обработки отсутствующих страниц Cloudflare Pages. Обновлены canonical, Open Graph и описание каждой страницы. Превью assets/social/portfolio-card.png — настоящий снимок первого экрана портфолио размером 1200×630; скриншоты представленных проектов не изменены.

Локальный scripts/preview.py запускается только на 127.0.0.1, обслуживает готовую папку, поддерживает адреса кейсов с .html и без расширения, возвращает собственную страницу с HTTP 404 и не показывает каталоги. Он не имитирует автоматически выполняемые Cloudflare перенаправления с .html. Порт можно поменять аргументом --port. Обычный python -m http.server не поддерживает адреса кейсов без расширения и не использует нашу страницу 404.
