WINDOWS / OCR / TTS / ПРОЕКТ

Read On Speak

Приложение для считывания субтитров из заданной области экрана и преобразования их в речь.

Обсудить похожий проект ↗Исходный код в приватном репозитории

Что реализовано

  • Захват изображения и Windows OCR
  • Несколько речевых движков, включая локальные варианты
  • Отдельные этапы генерации и воспроизведения аудио
  • Графический интерфейс, горячие клавиши и диагностические инструменты

Статус и ограничения

В README описаны показатели производительности и сборка приложения; результаты бенчмарков пока не подтверждались независимым запуском.

Техническое устройство

Конвейер обработки
Захват выбранной области экрана передаёт изображение в Windows OCR. Распознанный текст поступает в речевой движок; генерация аудио и его воспроизведение выделены в отдельные этапы.
Управление
Графический интерфейс и горячие клавиши управляют областью распознавания и чтением. Диагностические инструменты помогают разбирать поведение конвейера.
Окружение
Python-приложение рассчитано на Windows OCR и несколько вариантов TTS, включая локальные. Фактическая задержка зависит от оборудования и выбранного движка; замеры в этом портфолио не заявляются.

Основной сценарий

Пользователь выбирает область с субтитрами, настраивает голос и управляет чтением. Для демонстрации нужен отдельный ролик с тестовым текстом, без захвата личных окон.
